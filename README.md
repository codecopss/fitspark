# FitSpark 🚀

**FitSpark** is a modern fitness tracking web app designed to help users stay on top of their workouts, monitor progress, manage nutrition, and maintain a healthy lifestyle — all in one sleek interface.

## 🌟 Features

- 🏋️‍♂️ Workout Tracker
- 📈 Progress Visualization
- 🍎 Nutrition Section
- 👤 Editable User Profile
- 🌗 Dark Mode Toggle
- 🎨 Beautiful Gradient UI with Tailwind CSS

## 🛠 Tech Stack

- **React.js** — UI Library
- **React Router** — Page navigation
- **Tailwind CSS** — Utility-first styling
- **Lucide Icons** — Clean SVG icons

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/codecopss/fitspark.git
cd fitspark
```
## 2. **Install dependencies**

```bash
npm install
Run the development server

npm run dev
Your app should be running on http://localhost:5173.
```
## 3. Production Build

```bash
npm run build
Then preview it:
npm run preview
```
## ✨ Customization
You can modify theme colors in tailwind.config.js.

Add your backend and database (Firebase, Supabase, etc.) if you want persistent data.
